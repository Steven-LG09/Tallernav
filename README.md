# 🧭 React Native Navigation Examples

This project demonstrates different types of navigation patterns in **React Native** using common libraries and best practices. It’s designed as a reference for developers learning how to implement effective navigation in mobile apps.

## 🚀 What’s Included

- Stack Navigation
- Tab Navigation
- Drawer Navigation
- Nested Navigators
- Navigation with parameters
- Conditional navigation 

## 🛠️ Technologies Used

- React Native
- React Navigation
- Expo
